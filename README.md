# 🎯 POP QUIZ

**POP QUIZ** is a Kahoot-like interactive quiz system designed to make learning fun and engaging. This project enables hosts (teachers, trainers, or admins) to create quizzes and let participants join from both **web** and **mobile** platforms using either a **QR code** or a **game code**.

---

## 📌 Introduction

POP QUIZ is a dual-platform quiz system that supports:

- **Quiz creation and management** by hosts through a web application.
- **Quiz participation** by users through both a web interface and a mobile app.

The system aims to support real-time interactive quizzes in classrooms, training sessions, or any group learning environments.

---

## 🌐 Web Application (Laravel)

Built with the Laravel PHP framework, the web platform is mainly designed for **hosts** to manage quizzes.

### ✅ Features:
- 📝 Host registration
- 🔐 Host authentication
- ➕ Create new quizzes
- 📂 View all created quizzes
- 📤 Share quiz with participants
- 📊 View quiz results
- 🌐 Join quiz via quiz **URL**
- 🔢 Join quiz using **game code**

---

## 📱 Mobile Application (Flutter)

The mobile app, developed in Flutter, is focused on **participant interaction**.

### ✅ Features:
- 📷 Scan QR Code to join quiz
- 🔢 Join quiz using game code
- 📊 View quiz results
